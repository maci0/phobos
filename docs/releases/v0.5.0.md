# Phobos v0.5.0

Phobos can now check for Forge-X updates when it runs on the printer host and
Git is only installed inside the Forge-X chroot.

## Changes

- In Forge-X compatibility mode, Phobos uses the bundled Git, HTTPS helper,
  and CA certificates when the host Git executable is missing. The same
  runner handles update status, refresh, update, recovery, and rollback.
- Git commands still use the configured repository path. Paths that already
  include the chroot prefix are translated to the corresponding path inside it.
- Print-time metadata skips OrcaSlicer templates embedded in settings and reads
  the estimate from a standalone G-code comment. [Forge-X's matching fix](https://github.com/DrA1ex/ff5m/pull/115)

See the [Forge-X installation and rollback instructions](../../README.md#run-on-a-forge-x-printer).
