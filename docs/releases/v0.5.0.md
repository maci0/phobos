# Phobos v0.5.0

Run Phobos **inside the Forge-X chroot** for Forge-X updates. This puts the
updater's service verification and restart scripts in the environment they
expect.

## Changes

- In Forge-X compatibility mode, Phobos uses the bundled Git, HTTPS helper,
  and CA certificates when the host Git executable is missing. This lets
  a host-started daemon check for updates. The Forge-X service separately
  runs Git and curl to verify the update before changing the checkout.
- Print-time metadata skips OrcaSlicer templates embedded in settings and reads
  the estimate from a standalone G-code comment. [Forge-X's matching fix](https://github.com/DrA1ex/ff5m/pull/115)

On an AD5M running Forge-X beta `c58a891d`, the chroot's boot service brought
Phobos v0.5.0 back online after the printer rebooted.

See the [Forge-X installation and rollback instructions](../../README.md#run-on-a-forge-x-printer)
and the [service verification guide](../UPDATES.md#forge-x-service-verification).
