# phobos v0.4.0

This minor release adds the AD5X MIPS static release profile, deterministic
Moonraker ZIP package generation, portable serial termios configuration, and
firmware-specific printer installation guides. Zig 0.17.0, SQLite 3.54.1, and
the Moonraker reference pin `900848584374` are unchanged.

## Changes

The new `ad5x-mipsel` static release profile targets little-endian MIPS32r5 with
o32 hard float, 64-bit FPU registers, and NaN2008 for the FlashForge Adventurer 5X
running Z-Mod 1.7.4. The release helper validates ELF32 little-endian, o32 and
NaN2008 flags, MIPS32r5 ISA, and FP64 hard float ABI attributes, rejecting ISA
extensions and dynamic linkage.

The shared serial adapter removes redundant `termios.ispeed` and `ospeed` field
writes that are absent in MIPS Linux structures, configuring baud rates through
standard `cflag` bits. Serial tests verify 9600, 57600, 115200, and 230400 baud,
raw 8N1 framing, and bounded silent reads.

Deterministic Moonraker ZIP packages are now assembled alongside raw static
binaries. Each package wraps the verified static executable with GPLv3 license
text, `.version`, and Moonraker-compatible `release_info.json` containing the
project owner, name, version, and architecture-specific `asset_name`. The
release `SHA256SUMS` covers both raw binaries and ZIP archives.

Dedicated printer installation guides in the [README](../../README.md#printer-installation)
detail Forge-X production deployment, startup persistence via `start-stop-daemon`,
and isolated read-only trials for Z-Mod on the AD5M and AD5X.

## Verification

The test suite passes in Debug, ReleaseSafe, and ReleaseFast modes: 1,803 passed,
one gated real-Klippy skip, zero failures, and 342 bounded fuzz tests per mode.
All 121 Python tooling tests pass, including ELF fixture checks covering MIPS
byte order, NaN mode, float ABI, and ISA requirements, as well as deterministic
ZIP packaging tests. Build policy tests, ShellCheck, Zig formatting, Black,
Ruff, and mypy checks pass cleanly.

Registration coverage is 123/123 paths, 130/130 RPC methods, and 27/27 notifications
against upstream Moonraker, and 121/121 paths, 129/129 methods, and 28/28 notifications
against Forge-X.

All eight static Linux release profiles build and validate in ReleaseFast with
full LTO:
- `armv6-hardfp` (`arm-linux-musleabihf`, `arm1176jzf_s`)
- `armv7-soft` (`arm-linux-musleabi`, `generic+has_v7+aclass+soft_float`)
- `armv7-softfp-c` (`arm-linux-musleabi`, `generic+has_v7+aclass+vfp3`)
- `armv7-hardfp` (`arm-linux-musleabihf`, `generic+has_v7+aclass+vfp3d16`)
- `cortex-a7-hardfp` (`arm-linux-musleabihf`, `cortex_a7`)
- `aarch64` (`aarch64-linux-musl`, `baseline`)
- `x86_64` (`x86_64-linux-musl`, `baseline`)
- `ad5x-mipsel` (`mipsel-linux-musleabihf`, `mips32r5+fp64+nan2008`)

Production deployment verification is recorded in [provenance](https://github.com/maci0/phobos/blob/main/docs/PROVENANCE.md).

## Retained behavior and limits

API 1.5.0 and software version `phobos` identify this implementation; Forge-X's
API 1.4.0 is a separate reference. Python version fields remain a stub. Missing
CAN interfaces return an empty discovery list. Optional components remain
available when configured. Host reboot and shutdown remain no-ops; package
execution requires an injected runner. Full Jinja2, real LDAP, and real Apprise
remain outside scope; `klipper_estimator` requires an injected shell.

AD5X MIPS executables are verified for ABI and ELF structure; hardware execution
on an AD5X board remains uncertified. Z-Mod print macros and third-party
integrations remain separate compatibility work.
