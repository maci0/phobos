# phobos v0.1.4

Released 2026-10-20. Completes the low-level standard-library review across
first-party Zig code and the filesystem-capacity C adapter. Checked APIs and
remaining adapter limits are recorded in [STDLIB.md](../STDLIB.md).

Serial reads preserve leading bytes and configure raw 8N1 correctly. Inotify
reads and cancellation use native files and futures. Camera capability queries
use typed device control. Virtual files stream to a bounded owned allocation
even when their reported size is zero. Capture output uses Zig string formatting.

Temperature and G-code stores use bounded `std.Deque` instances. Klippy framing
uses native delimiter readers with persistent buffering. MQTT lengths use
bounded LEB128 readers and writers. HTTP paths use native percent decoding and
reject invalid UTF-8; query-only plus decoding preserves literal plus signs in
file paths. Standard searches, tokenizers, case conversion and calendar helpers
replace duplicate primitives. RSS parsing rejects truncated markup without
panicking and releases partially allocated items.

File operations use checked directory handles within the selected registered
root. Native canonicalization resolves nested links and `..` correctly, while
escaping links are rejected. Metadata, listings, downloads, copies and mutations
share this path handling. Disk capacity uses `fstatvfs` on the checked directory.
Copies and uploads use native atomic replacement. A truncated upload file part
preserves an existing destination; a multipart form is not a transaction.

Git command arguments use `std.mem.concat` instead of an eight-slot buffer.
Update tests fetch local temporary repositories rather than the checkout's
remote. Refresh tests now assert the created remote-tracking ref.

## Verification

- Host suite: 1435 passed, 1 skipped, 0 failed; 246 fuzz tests discovered.
  The skip is the gated host real-Klippy test whose local socket is absent.
- Tests cover serial bytes and PTY settings, persistent and truncated frames,
  malformed RSS, exact allocation ownership, allocation failures, bounded store
  eviction, encoded HTTP filenames, symlink escapes, nested aliases, recursive
  copies, failed upload replacement and long process argument lists.
- Static ARM ReleaseSafe binary runs inside the real Forge-X 1.4.2 chroot on
  `127.0.0.1:7126`, using the copied database. Checks include 100 concurrent
  HTTP reads, three WebSocket methods, real Klippy queries, camera and serial
  enumeration, encoded sensor queries and a 12,210,964-byte G-code download.
- Temperature fields advance by three samples over 2.2 seconds. Disk-capacity
  totals match the running service at 6,196,731,904 bytes. Config downloads
  through the symlinked registered root match. Separate temporary ARM fixtures
  resolve a nested link with `..` to the correct file and reject three escaping
  download, metadata and directory requests with 403.
- API coverage remains 123/123 endpoints, 130/130 methods and 27/27
  notifications. Generated API documents were not regenerated. Graphify is
  unavailable, so its graph was not updated.
- Probes are stopped after verification, with no listener on 7126. Production
  phobos v0.1.2 on 7125 remains ready, with the last print complete and both
  heater targets zero. The board boot ID is unchanged. This release is not
  installed onto the printer. No printer restart, motion, heating, print start,
  firmware restart, real update, board reboot or shutdown was performed.

## Retained differences

| Classification | Behavior and reason |
| --- | --- |
| Code bugs, fixed | Lost buffered bytes, short owned allocations, malformed RSS panic, unchecked root symlinks, destructive failed uploads and fixed Git argument capacity. |
| Identity, kept | API 1.5.0 and `moonraker_version: phobos` identify the implementation and vendored API pin. Forge-X's older API 1.4.0 is not substituted. |
| Identity, kept | Cached Git status retains `name` and `g69663338`. The pinned upstream emits `name`, uses `--abbrev=8`, and preserves the cached full version. Older Forge-X reported a seven-digit abbreviation of the same commit. |
| Identity, kept | Python version fields remain explicit stubs. Missing CAN interfaces return an empty UUID list instead of a 500. |
| Environment | A fresh probe has its own temperature-history age and WebSocket counts. Host OS, CPU and NIC values differ; hardware checks run inside the printer chroot. |
| Environment | Optional components are selected by configuration. Components omitted by Forge-X retain their implementations when registered. |

The narrow termios, inotify, system-identity, V4L2, SQLite and filesystem-capacity
adapters remain where Zig 0.17 has no matching complete API. Client WebSocket
masking, Base32, UUID layout and application grammars remain local over standard
primitives. Full Jinja2, LDAP and Apprise remain outside scope;
`klipper_estimator` requires an injected shell.
