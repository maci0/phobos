# phobos v0.2.0

Released 2026-10-21. This minor release consolidates the reviewed daemon
integrations already published in [v0.1.5](v0.1.5.md). Runtime source is unchanged
from v0.1.5; the package version and release documentation advance to 0.2.0.
Zig 0.17.0 and the Moonraker reference pin `900848584374` remain unchanged.

The integration audit compared the retired local clones against main. Their
intended changes were already incorporated or superseded by the reviewed fixes
recorded in [the verification ledger](../PROVENANCE.md). Unique historical
commits and working files were archived before 38 inactive clones were removed.
Intentionally dirty negative-test fixtures remain separate from the release.

The complete Debug suite passes 1717 tests with one gated real-Klippy skip and
zero failures; 325 bounded fuzz harnesses are discovered. All 88 Python scanner
and measurement-tool tests pass. An initial run of the older v0.1.5 test artifact
hit a simulated-Klippy connection race; the version-matched complete suite passes.
The regular build runner timed out; the documented standalone runner was used.

The retained feature limits and hardware verification from v0.1.5 still apply.
No motion, heating, print start, firmware update, Klipper restart or board reboot
was requested by the release checks.

API registration coverage is 123/123 endpoints, 130/130 methods and 27/27
notifications. The checked-in 54-event external golden replay retains seven
pre-existing mismatches, reproduced against published v0.1.5: three server-info
comparisons see the intentionally registered `octoprint_compat` and
`update_manager` components; two file-root comparisons expose the harness's
checkout-path normalization; two USB comparisons see 26 devices on this host
instead of the capture's 32, with the same device key schema. The original
golden capture and strict comparison were preserved. This is not a claim that
that external replay passes.

Static x86-64 musl and Cortex-A7 ARM hard-float ReleaseSmall binaries are
provided with SHA-256 checksums. The exact ARM asset passed a private-database
printer probe on loopback port 7126, including cold readiness and twenty
read-only API requests. No components failed; heater targets remained zero.
The probe was stopped afterward.
